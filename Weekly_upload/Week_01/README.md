# 📚 Week 01 · 论文简介

## 1) GLEE

- 论文 PDF：[`GLEE.pdf`](./GLEE.pdf)
- 一句话结论：**GLEE 试图把检测、分割、跟踪、grounding 等对象级任务统一到一个开放世界框架里。**

### 核心贡献

1. 统一对象感知框架：同一模型处理多类下游任务。  
2. 多模态输入支持：图像编码器 + 文本编码器 + visual prompt。  
3. 多源监督协同训练：兼容不同标注粒度的数据。  
4. 强调零样本迁移：面向未见类别/场景的泛化能力。

### 方法亮点（简）

- 通过统一表示学习减少任务割裂。
- 将“可提示（promptable）”能力扩展到对象级理解链路。

### 启发与可复用点

- 如果团队要做“一个模型覆盖多任务”的视觉底座，GLEE 的统一范式值得参考。
- 在项目中可先从“检测 + grounding”二合一开始，再逐步扩展到分割/跟踪。

---

## 2) Qwen-VL

- 论文 PDF：[`qwen-vl.pdf`](./qwen-vl.pdf)
- 一句话结论：**Qwen-VL 是面向中文/多语场景可用性较强的通用视觉语言模型，覆盖图文理解、问答、定位等任务。**

### 核心贡献

1. 提供通用 LVLM 与对话版本（Qwen-VL / Qwen-VL-Chat）。  
2. 在 caption、VQA、文档理解、grounding 等任务表现均衡。  
3. 支持多轮图文交互，强调实际使用体验。  
4. 对中文生态更友好，便于中文业务快速落地。

### 方法亮点（简）

- 兼顾“通用能力 + 交互能力”，不是只追单项 benchmark。
- 在实际应用中可直接用于“图文问答/检索辅助/图像定位解释”。

### 启发与可复用点

- 适合作为多模态应用的默认基线模型。
- 与内部知识库结合后，可快速构建“看图问答 + 文档问答”原型。

## 本周总结

Week 01 的主线是：**统一对象感知（GLEE） + 通用图文理解（Qwen-VL）**。  
前者偏视觉任务统一，后者偏多模态交互落地，二者可形成互补。
